# OFI Feature Construction

This project focuses on feature construction for Order Flow Imbalance (OFI) analysis. The project contains a Jupyter notebook that demonstrates the feature construction process using a sample dataset.

## Project Structure

- `OFI_Feature_Construction.ipynb`: Main Jupyter notebook containing the feature construction code and analysis
- `first_25000_rows.csv`: Sample dataset used for analysis

## Getting Started

1. Clone this repository
2. Open the Jupyter notebook using Jupyter Lab or Jupyter Notebook
3. Run the cells in the notebook to see the feature construction process

## Requirements

- Python 3.x
- Jupyter Notebook/Lab
- Pandas
- NumPy

## Usage

The notebook contains detailed documentation and step-by-step instructions for the feature construction process. Follow the cells in order to understand and reproduce the analysis.
